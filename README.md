# Nike Sales Dashboard – Power BI

## Overview

This project analyzes Nike sales performance using Power BI, focusing on regional trends, product categories, customer behavior, and business KPIs.

The objective is to transform raw sales data into actionable insights through interactive dashboards and visual analytics.

---

## Business Problem

Nike generates large volumes of sales data across multiple regions and product categories.

This dashboard helps answer questions such as:

- Which regions generate the highest revenue?
- How do sales evolve over time?
- Which product categories perform best?
- What color preferences drive sales?
- Which KPIs should management monitor?

---

## Dataset

The dataset contains Nike sales information including:

- Revenue
- Units Sold
- Product Categories
- Product Colors
- Regions
- Sales Dates
