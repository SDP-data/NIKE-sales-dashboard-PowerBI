# Nike Sales Dashboard — Power BI

Power BI dashboard project focused on analyzing Nike sales performance across regions, product categories and color trends.

---

## Project Overview

This project was developed as part of a Data Analytics final project with the objective of transforming raw sales data into meaningful business insights through interactive dashboards and data visualization.

The analysis includes:
- Regional sales performance
- Sales trends over time
- Product color analysis
- KPI tracking
- Interactive dashboard navigation
- Data modeling and DAX measures

---

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
